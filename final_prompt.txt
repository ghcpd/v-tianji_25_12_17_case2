Prompt

Problem Statement:
Create a sleek, modern, highly interactive short-video browsing web interface inspired by TikTok. Build a small, visually polished, smooth-scrolling Web UI project from scratch using Vue or React (your choice).

Requirements:
Create a complete, runnable project from zero.

The application should be frontend-only and use mock or in-memory data (no real backend required).

Implement a clean, well-structured component architecture with clear state management for video feeds, playback state, likes, comments, and user interactions.

Support smooth vertical scrolling, auto-play behavior for the active video, and basic interaction features such as like, pause/play, and follow-style UI elements (mocked).

Generate full unit test coverage that verifies core UI logic, scrolling behavior triggers, and interaction state changes.

All tests must be executed and pass successfully.

Run the project to ensure it boots and functions correctly.

If any step fails, debug, fix, and re-run until everything passes.

Do not assume success—treat this as a real execution environment.

Deliverables:
Full project structure

All source code files

All test files

All configuration files

Commands used to install dependencies, run tests, and start the development server

Logs from running tests and launching the dev server

A short summary after a successful run
